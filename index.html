Cài Đặt & Sử Dụng SASS với npm & SASS CLI

Biên dịch SCSS sang CSS với Dart Sass CLI, chế độ --watch và quản lý thư mục

1. Kiểm tra Node.js & npm

Kiểm tra môi trường runtime bằng lệnh node -v và npm -v để đảm bảo sẵn sàng cài đặt package.

2. Cài đặt SASS CLI

Cài đặt toàn cục thông qua npm install -g sass hoặc sử dụng npx sass, kiểm tra bằng sass --version.

3. Chế độ Watch Mode

Tự động theo dõi các thay đổi và biên dịch tức thì với cờ --watch: sass scss/:css/ --watch.

Biên Dịch Nhiều File SCSS (scss/:css/)

Cấu trúc SCSS dạng module hóa với _variables.scss, _mixins.scss và main.scss giúp mã nguồn rõ ràng, dễ bảo trì và mở rộng.
